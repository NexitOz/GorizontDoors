# GORIZONT

Интерактивный журнал скрытых дверей на основе окончательного каталога 2026 года. Все 11 разделов, адаптивные страницы и развороты, открывание Avers/Revers, профили, отделки, конструкция, акустика и дополнительные опции.

## Запуск

Нужен Node.js 22.18 или новее. Для совпадения с проверенным окружением используйте Node.js 24.

```sh
npm ci
npm run dev
```

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Сборка находится в dist. Vercel определяет Vite; параметры заданы в vercel.json. Для другого статического сервера достаточно раздавать dist. Прямые ссылки используют параметр ?page=, серверный роутинг не нужен.

3D загружается только при открытии соответствующей страницы. Когда WebGL недоступен, сохраняются схема двери, текст, навигация и контроллеры.

## Управление

- Телефон: горизонтальный свайп на свободной области листает; вертикальный жест прокручивает страницу.
- Компьютер: стрелки, клавиши Left/Right, Home/End и перетягивание внешней кромки.
- Дверь: нажатие на полотно или ручку, перетягивание и ползунок угла.
- Оглавление, исходный PDF, увеличение узлов и отдельный выключатель звука.
- Avers движется к наблюдателю, Revers за плоскость стены. Сторона петель переключается отдельно.
